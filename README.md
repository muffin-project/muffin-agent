# muffin-next

Ground-up rebuild of Muffin, following the blueprint in the `Muffin` repo
(`docs/blueprint/`, branch `claude/muffin-muffinos-refactor-37eda9`).

Named `muffin-next` only during the strangler transition — macOS is
case-insensitive, so `muffin` would collide with the existing checkout.
Renamed at cutover.

Status: M0 in progress (policy kernel + traces). Nothing runs yet.

Normative contracts: `docs/blueprint/09-contratti-m0-m1.md` in the blueprint repo.
Language policy: English in code and public docs, Italian for persona, prompts
and design records (ADR-0020).
