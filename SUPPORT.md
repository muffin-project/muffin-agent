# Supporting Muffin

Muffin is owner-led and developed in public with contributors around it.

## Financial support

If you want to help fund development, infrastructure and the time spent building
Muffin, you can donate through PayPal:

https://www.paypal.com/donate/?hosted_button_id=MB89Z9ZLFKFSW

Support is appreciated, but it is deliberately separate from project authority.
A donation does **not** grant repository write access, merge or release rights,
maintainer status, product authority, or priority over technical decisions.

Public support acknowledgements are opt-in. Donations do not grant repository
access or project authority.

## Contributing is different

You do not need to donate to contribute. Code, documentation, testing, bug
reports, security work and thoughtful review are all valuable. Start with
[CONTRIBUTING.md](CONTRIBUTING.md).

## Contact
