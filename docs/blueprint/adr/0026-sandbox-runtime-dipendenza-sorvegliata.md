# ADR-0026 — Executor sandboxato: `@anthropic-ai/sandbox-runtime` come dipendenza sorvegliata

**Contesto.** ADR-0018 prescrive l'esecuzione sandboxata di default (Seatbelt/bubblewrap, doppio layer fs+rete, proxy allow-only, mandatory deny paths). Restava aperto il *come*: dipendere dalla libreria di Anthropic o generare i profili in casa. Evidenza fresca (M3-A, 2026-08-08, con clone+build+esecuzione del codice): il pacchetto è attivissimo (v0.0.71 uscita ieri, 71 release in 292 giorni) ma perenne `0.0.x`; API da libreria **esattamente della nostra forma** (singleton initialize-once/wrap-many, `customConfig` per-invocazione per il write-scope per-turno, restituisce la stringa avvolta e **lo spawn resta nostro**); 4 dipendenze dirette, zero transitive; un profilo SBPL reale pesa 11-19KB di cui ~70% è template di compatibilità Chrome-derivato **ancora in fase di scoperta upstream** (#430); e un cluster di bug "**fail silenzioso della policy**" aperti nell'ultima settimana: #432 (mandatory deny macOS ancorati a `process.cwd()`, contro la garanzia del README), #434 (chiavi di config sconosciute ignorate in silenzio), #446 (Linux, `allowWrite` che diventa read-only per ordine dei mount).

**Decisione.** Si adotta `@anthropic-ai/sandbox-runtime` come dipendenza runtime, **pinnata esatta** (niente caret; upgrade = atto deliberato che ri-esegue la suite di probe), **dietro un confine nostro** (`core/sandbox/executor.ts`): la config è la nostra, parsata con zod v4, e l'oggetto srt viene **costruito programmaticamente campo per campo** — mai passato per pass-through, così il typo di chiave (#434) è impossibile per costruzione. Ogni garanzia su cui ci appoggiamo ha il suo **tracer bullet** (pratica §2), eseguito da `doctor` e prima del primo exec di sessione, ciascuno mappato al bug che sorveglia: (1) write fuori scope negata; (2) write su un deny path (RoT, config, secrets) negata **con cwd diverso da home** (→ #432); (3) write dentro lo scope **riesce** (→ #446 — un contenimento che contiene tutto è rotto anche lui); (4) rete verso host non consentito bloccata; (5) rete verso host consentito via proxy funziona. Un probe che fallisce → le capability exec degradano ad ASK e `doctor` lo dichiara (regola 5 di ADR-0018), mai silenziosamente unsandboxed — su questo divergiamo dal default fail-open di Claude Code. Limiti dichiarati v1: niente PTY (shell non-interattiva by design — schiva il cluster #419); su Linux si salta il layer opzionale `apply-seccomp` (`allowAllUnixSockets: true` — schiva #428/#429, si perde l'hardening Unix-socket); l'executor chiama `cleanupAfterCommand()` dopo ogni run (ghost dotfiles); `doctor` controlla la lunghezza di `TMPDIR` su Linux (#213). Il rimedio AppArmor per Ubuntu 24.04 va nell'installer (campo-testato sul VPS del vecchio Muffin; il consiglio ufficiale — solo sysctl — è dimostrato insufficiente da #428/#429). La duplicazione zod v3/v4 nel tree è un costo accettato.

**Alternative scartate.** *Profili in casa*: le 20-40 righe del caso minimo sono un'illusione — le ~150 righe di compatibilità (mach-lookup, sysctl, iokit) sono il lavoro vero, upstream lo sta ancora scoprendo a colpi di issue, e ci porteremmo in casa anche proxy HTTP+SOCKS e bridge socat; è riscrivere roba risolta (principio di ADR-0015) per zero valore differenziale. *Profili statici alla Gemini CLI*: perdono il write-scope per-turno, che per noi è normativo (§3-bis). *Docker/microVM*: già scartati in ADR-0018 (tier di isolamento sproporzionato all'oversight). *Aspettare la 1.0*: nessun segnale che arrivi; il sandbox integrato in Claude Code è enforcement di produzione sullo stesso codice.

**Conseguenze.** Più facile: mesi di compatibilità Seatbelt/bwrap e l'intero egress proxy arrivano risolti; il write-scope per-turno è un parametro, non un generatore di profili da mantenere. Più difficile: sorveglianza attiva di una `0.0.x` (il pin esatto la rende governabile); i nostri probe devono restare la fonte di verità sulla postura — la fiducia sta nel probe, non nel README (è la lezione delle quattro difese scollegate, applicata a una dipendenza).

**Reversibilità.** Alta: il confine `runContained(cmd, scope)` è nostro; sostituire srt con profili propri o con microVM è un cambio di executor, non di architettura (già inquadrato da ADR-0018). Segnali che era sbagliata: probe che falliscono ripetutamente attraverso le versioni; collasso della cadenza di release upstream; overhead misurato in M3 (dovuto, gap A6 §5.6) oltre la soglia percepibile nell'uso quotidiano.
