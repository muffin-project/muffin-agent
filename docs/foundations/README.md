# Legacy foundations corpus

This directory predates the current repository authority model.

- `VISION.md` is now a tombstone to the current `docs/VISION.md`.
- `COGNITIVE_BASES.md`, `UNDERSTANDING.md`, `INVARIANTS.md` and `REFERENCES.md`
  are inherited cognitive/design source material. They may contain useful
  evidence or principles, but they are **not current implementation/status
  authority**.

Current homes:

- product destination → `docs/VISION.md`;
- current architecture → `docs/ARCHITECTURE.md`;
- current security → `docs/SECURITY.md`;
- decision principles → `docs/DESIGN-PRINCIPLES.md`;
- curated cognitive problem/evidence corpus → `docs/blueprint/knowledge/`;
- dated external research → `docs/blueprint/research/`.

The legacy files stay at stable paths until unique live material has been
explicitly extracted and references can be migrated safely. Do not load this
whole directory as startup context.
