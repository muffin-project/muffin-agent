# Foundations, historical

Two different materials live here. They are deliberately **not** merged: they
have different provenance and answer different questions.

| | What it is |
|---|---|
| `VISION-pre-authority.md` | The single foundation document extracted on 2026-08-19, preserved in the form it had before `docs/VISION.md` became the product authority. One document, one purpose: showing what the north star said before the authority model existed. |
| `legacy/` | The inherited foundations corpus, moved here whole on 2026-08-31: `COGNITIVE_BASES.md`, `INVARIANTS.md`, `REFERENCES.md`, `UNDERSTANDING.md`, and the corpus's own `README.md`. It predates the current repository authority model. |

**Neither governs HEAD.** Nothing was extracted, promoted or rewritten when this
material was archived: `legacy/` is the corpus as it stood, including claims the
current design has since abandoned, and including references to paths of the old
Muffin repository that never existed here.

`legacy/` is kept readable in the checkout — rather than left to Git alone —
because the architecture reconciliation (**F2**) will read it explicitly. After
F2 it is a fair question whether it still earns that place; it is not a question
for today.

For current authority start at `docs/README.md`.

`docs/foundations/` no longer exists. The redirect that lived at
`docs/foundations/VISION.md` was removed on 2026-09-01, once nothing current
pointed at it; the current north star is `docs/VISION.md`. Neither that redirect
nor `docs/VISION.md` is part of this corpus.
