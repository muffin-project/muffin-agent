   (a) il launcher `~/.local/bin/muffin` è un symlink con shebang
   `#!/usr/bin/env node`, ma il Node che l'installer mette sotto
   `~/.local/share/muffin/node/bin` non è nel PATH di nessuna shell: su una
   macchina senza Node di sistema `muffin` non parte dopo l'installer
   (`/usr/bin/env: 'node': No such file or directory`); il test
   `evals/install/ubuntu.sh` ri-aggiunge quel PATH a mano e per questo resta
   verde. (b) Da `su - muffin` non esiste il bus systemd dell'utente («Failed
   to connect to bus: No medium found»): la unit viene scritta, il gateway non
   parte, exit 3. Sulla VPS è il caso normale, non un caso limite. Entrambi
   sono difetti meccanici dentro A11; il rimedio a mano è aggiungere
   `~/.local/share/muffin/node/bin` e `~/.local/bin` al PATH e, da root,
   `loginctl enable-linger <utente>` prima di `muffin gateway install
   --write --start`.
3. **Sudo.** L'utente appena creato non ha sudo senza password: bubblewrap,
