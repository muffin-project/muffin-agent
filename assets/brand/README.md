# Muffin visual identity · v0.1

This folder is the current visual source for Muffin. It is deliberately small: it records the decisions we have actually made, without pretending the brand is finished.

## Canonical mark

`muffin-mark.png` is the current canonical raster mark, derived from the approved **Iconic → Minimal → Pure** exploration.

Current decisions:

- Muffin must remain unmistakably a muffin/cupcake; the wrapper is part of the silhouette.
- Minimal face: two neutral eyes, no permanent mouth or accessory.
- **No monocle** in the canonical mark.
- Do not redraw the mark into a generic blob, orb, robot or “AI” symbol.
- Preserve the mark's proportions and recognizable silhouette when deriving future assets.
- `muffin-mark-32.png` is the current small-surface convenience asset.

## Current palette

The palette is **v0.1 / provisional**. It comes from the chosen visual direction; it is not permanent brand law.

| Token | Value | Current role |
|---|---|---|
| Ink | `#111315` | outline / structure |
| Muffin orange | `#F06B2A` | identity accent / wrapper |
| Cream | `#FEF7E8` | Muffin top / warm surface |
| Paper | `#FCF9F5` | optional warm neutral |
| Muted line | `#D9D3C9` | secondary structure |

See `palette.svg` for a quick swatch reference.

## README banner

The root README uses `../readme/banner-light.png` and `../readme/banner-dark.png`.

Both banners have **transparent backgrounds**, so GitHub supplies the real page background. The variants differ only where linework needs contrast in light vs dark themes.

The composition is intentionally human-first: the person remains central; Muffin sits on the continuity thread as a recognizable presence rather than becoming the center of the person's life.

## Status

This is not a finished brand system. Wordmark, typography, expression set and broader visual grammar are still open. Future work should evolve this folder deliberately rather than silently inventing a different Muffin in each surface.
