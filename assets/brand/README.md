# Muffin visual identity · v0.1

This folder is the current visual source for Muffin. It is deliberately small.

## Canonical mark

`muffin-mark.png` is the raster master derived from the approved **M1 PURE** exploration.

Current decisions:

- Muffin must remain unmistakably a muffin/cupcake; the wrapper is part of the silhouette.
- Minimal face: two neutral eyes, no permanent mouth or accessory.
- **No monocle** in the canonical mark.
- Do not redraw the mark into a generic blob, orb, robot or “AI” symbol.
- Preserve the mark's proportions and recognizable silhouette when deriving sizes.
- `muffin-avatar.png` is the current ready-to-use square avatar.
- `muffin-mark-64.png` and `muffin-mark-32.png` are convenience sizes for small UI surfaces.

## Current palette

The palette is **v0.1 / provisional**, extracted from the chosen visual direction rather than treated as permanent brand law.

| Token | Value | Use |
|---|---|---|
| Ink | `#111315` | outlines, structure |
| Muffin orange | `#F06B2A` | identity accent / wrapper |
| Cream | `#FEF7E8` | Muffin top / warm surface |
| Paper | `#FCF9F5` | light neutral |
| Muted line | `#D9D3C9` | secondary structure |

See `palette.svg`.

## README banner

The root README uses:

- `../readme/banner-light.png`
- `../readme/banner-dark.png`

Both have transparent backgrounds so GitHub supplies the actual page background. The two variants exist only to keep the linework readable in light and dark themes.

The composition is intentionally human-first: the person stays central; Muffin is a recognizable presence on the continuity thread rather than the center of the person's life.

## Status

This is **not a finished brand system**. It records the visual decisions that are already intentional so future README/site/app work does not silently reinvent Muffin.
