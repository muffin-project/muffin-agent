# Muffin visual identity · v0.1

This folder is the small, practical source of truth for Muffin's current visual identity. It records decisions we have actually made without pretending the brand is finished.

## Canonical direction

**Iconic → Minimal → Pure → no monocle.**

`muffin-mark.svg` is the canonical master mark. The shape comes from the approved visual exploration: an unmistakable muffin/cupcake, a wrapper that is part of the silhouette, a warm cream top, two neutral eyes and no permanent mouth or accessory.

Do not silently redraw Muffin into a blob, orb, robot, brain icon or generic “AI” mascot. Future variants must preserve the canonical silhouette and proportions.

## Asset set

- `muffin-mark.svg` — canonical color master;
- `muffin-mark-mono.svg` — single-ink outline treatment;
- `muffin-mark-inverse.svg` — dark-surface treatment;
- `muffin-mark-64.png` and `muffin-mark-32.png` — small raster convenience exports;
- `muffin-thinking.svg` — attentive / processing expression;
- `muffin-skeptical.svg` — checking / not-convinced expression;
- `muffin-quiet.svg` — listening / no-rush expression;
- `palette.svg` — v0.1 palette reference.

Expression variants may change the face and a small semantic accent. They must not silently change the body, wrapper or overall silhouette.

## Visual grammar

```text
Muffin / human layer   system layer
soft                   exact
organic                geometric
warm                   cool / neutral
character              contracts
```

Shorthand: **Human first. System strong. Muffin present.**

## Palette

| Token | Value | Role |
|---|---|---|
| Ink | `#07162C` | outline / structure / eyes |
| Muffin orange | `#FF7A1A` | identity / wrapper |
| Cream | `#FFF9EE` | Muffin top / warm surface |
| Paper | `#FAF6EE` | optional warm background |
| System blue | `#1878F2` | sparse technical accent |
| Inverse line | `#F8EEDC` | linework on dark surfaces |

Orange belongs to Muffin and human-facing emphasis. Blue is a sparse system/technical accent, not a default gradient or generic AI treatment.

## Status

**Draft v0.1.** This is not a finished brand book. Typography, wordmark, motion language and the broader product design system remain open. Change this folder deliberately rather than inventing a different Muffin per surface.
